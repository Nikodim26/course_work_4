# Приложение E-commerce
## Данный проект предназначен для электронной торговли (или электронной коммерции)
class Category создает именованый объект - перечень продуктов
class Product создает именованый объект - продукт, один из, входящих Category
Функция reading_file создает объекты Category и Product путем считывания данных с файла.
## Установка
Проект можно скачать архивом с GitHub и использовать при помощи PyCharm. *.exe пока нет
